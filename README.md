Project Overview
This project focuses on monitoring electricity consumption and simplifying electricity bill calculation. The system uses Arduino and sensors to collect consumption-related data, while a billing module calculates the estimated electricity charges based on usage and applicable tariff rates.

Objectives
Monitor electricity consumption in real time.
Track electricity usage over time.
Calculate estimated electricity bills based on units consumed.
Provide a convenient way to review consumption history.
Support notifications and electricity usage monitoring.

Hardware Components
Arduino Uno 
16×2 LCD Display
0–25V Voltage Sensor Module
ACS712 Current Sensor Module
HC-05 Bluetooth Module
Relay Module

Technologies Used
Microcontroller: Arduino
Programming: Embedded C
Database: MySQL

Working Principle
The Arduino-based system collects electricity consumption data using the connected sensors.
The collected readings are used to monitor electricity usage.
The billing module calculates estimated charges using the recorded units and configured tariff rates.
Consumption data is stored to support historical usage tracking.
The monitoring interface presents consumption information and supports notifications where implemented.

Key Features
Real-time electricity consumption monitoring
Electricity usage history
Automated bill estimation
Tariff-based billing calculation
Consumption notifications and monitoring interface

Applications
Residential electricity monitoring
Electricity usage tracking
Consumption based bill estimation
Energy management systems

Project Outcome
The project demonstrates the use of microcontrollers, sensors, embedded programming and database technologies to develop an automated electricity monitoring and billing solution.

Project Status
Academic project.
